This map uses Volunteered Geographic Information from climbers around the United States to display how many climbs are in each state. The data has not been processed in any way - the map simply displays raw count data. 50 values were collected from the Mountain Project website and added to an excel file with a FID and state name for each row. The excel file was converted to a csv file which, in ArcGIS Pro, could be joined to the us-states shapefile provided in the lab. I also did a batch field delete for any that weren't needed just to prevent issues further down the road. Then I used the software's built in features to calculate the natural breaks in my data, and have a visualization I was more comfortable with to compare my final webmap to. Finally, I used geojson.io to convert the newly downloaded shapefiles to GeoJSON. 

Symbolization of the data was simple: I had recorded the breaks that ArcGIS determined and simply put those into the javascript portion of the code. I used color brewer to find a scheme I liked. I needed just a single-hue scheme; since the data was nothing fancy, the symbolgy didn't need to be.
